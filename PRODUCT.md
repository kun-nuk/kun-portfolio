# PRODUCT.md

## Product
KUN UX/UI Designer Portfolio is a personal portfolio and case-study website for presenting KUN's UX/UI, app, web, AIGC, IP, and individual practice work.

## Audience
Hiring managers, design leads, founders, and collaborators who need to assess visual craft, product thinking, and execution quality quickly.

## Primary Jobs
- Show KUN's identity and contact information clearly.
- Let visitors scan homepage project cards and open detailed case pages.
- Present each case with source-backed visuals and readable project context.
- Keep local static output usable without a running dev server.

## Design Principles
- Case evidence first: use real project images at readable scale, with text extracted and structured separately when screenshots are too small.
- Distinct per case: the portfolio shell can be dark and expressive, while each case page may inherit its own source project visual language.
- Reduce noise: decorative grids, glows, and ornaments should never compete with text or screenshots.
- Responsive rigor: no text or image overflow across desktop and mobile.
- Editable structure: prefer HTML text and local image assets over embedded PDFs or screenshot-only pages.

## Visual Voice
Precise, case-led, polished, and technology-aware. Avoid generic portfolio cards, unreadable screenshot walls, excessive background patterns, and effects that distract from the work.
